# 意难平 Skill - 使用说明

## 快速开始

在 Claude Code 或 OpenClaw 中输入：

```
/意难平
```

你会看到两个问题：

1. **你和TA的关系是什么？**
   - 暗恋对象
   - 前任
   - 错过的缘分
   - 其他

2. **你想回到什么时候？**
   - 高中时代
   - 大学时代
   - 刚毕业那几年
   - 其他（如"2019年夏天"）

然后提供一段聊天记录，AI会学习TA的说话风格和性格。

## 示例流程

```
用户: /意难平

AI: 嗯，我准备好了。先告诉我——你和TA是什么关系？
    可以选一个：
    - 💭 暗恋对象
    - 💔 前任
    - 🌙 错过的缘分
    - ✏️ 其他

用户: 暗恋对象

AI: 明白了。那你想回到什么时候？
    - 🏫 高中时代
    - 🎓 大学时代
    - 💼 刚毕业那几年
    - ✏️ 其他

用户: 高中时代，2018年

AI: 好的，我记住了。现在把你们的聊天记录发给我吧。

用户: [粘贴聊天记录...]

AI: 收到了，让我分析一下...
    [展示分析结果]
    觉得准确吗？需要调整吗？

用户: 她没那么傲娇，其实挺温柔的

AI: 好的，我调低傲娇度，提高温柔度...
    [更新结果]
    还有什么要调整的吗？

用户: 没有了

AI: 要给她起个名字吗？

用户: 叫她小月吧

AI: ✅ 创建完成！之后输入 /意难平-对话 小月 就可以和她聊天了。
```

## 命令列表

| 命令 | 说明 |
|------|------|
| `/意难平` | 创建一个新的人物模拟 |
| `/意难平-列表` | 查看已创建的所有人物 |
| `/意难平-对话 {名字}` | 进入对话模式 |
| `/意难平-调整 {名字}` | 调整人物的性格参数 |
| `/意难平-删除 {名字}` | 删除人物 |

## 注意事项

1. **时代限定严格**：模拟的人物不会知道那个时代之后的事。比如2018年的人不会知道疫情。

2. **基于真实数据**：聊天记录越真实越长，还原度越高。建议至少30轮对话。

3. **校准很重要**：AI分析可能不准，请务必根据自己的印象校准。

4. **情感安全**：这是模拟和疗愈，不是让你沉溺。如果觉得不适，随时可以停止。
